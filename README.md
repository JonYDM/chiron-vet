# 🐾 Chiron

**Software de gestión para veterinarias** — pensado para el mercado latinoamericano, iniciando en Morelos, México.

> El nombre viene de *Quirón (Chiron)*, el centauro sabio de la mitología griega, maestro de la medicina.

---

## ¿Qué es?

Chiron es un SaaS (software por suscripción) para veterinarias de nivel medio que buscan digitalizar y mejorar su operación. No inventamos una categoría nueva: **mejoramos lo existente** con un producto más simple, accesible y con un diferenciador clave.

### Diferenciador clave
🟢 **Recordatorios automáticos por WhatsApp** de citas, vacunas y desparasitaciones — para que los clientes regresen y el negocio gane más.

---

## Funcionalidades (en construcción)

- 👤 Gestión de clientes (dueños) y mascotas
- 📋 Expediente médico (consultas, vacunas, desparasitaciones)
- 📅 Agenda de citas
- 🔔 Recordatorios automáticos (WhatsApp)
- 🛒 Punto de venta (alimento, medicina, accesorios)
